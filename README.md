## What I'm working on

### [OpenOmada Device Agent](https://github.com/adryanalencar/open-omada-device-agent)

An experimental, unofficial implementation of the device side of the **Omada ECSP protocol**.

The goal is to make devices outside the Omada ecosystem — starting with **OpenWrt** — discoverable, adoptable and manageable by an Omada controller, while documenting the protocol and building a reusable foundation for future device adapters.
